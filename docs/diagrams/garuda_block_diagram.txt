The overall block diagram of Project Garuda shows the system organised into three horizontal layers. The inference pipeline layer (top) carries video from the camera through the GStreamer TAPPAS pipeline into the Hailo-8L NPU, which runs YOLOv8/v6 object detection and classifies detections as watch targets (Person) or danger objects (Knife, Scissors, Hammer). The response and control layer (middle) contains the Alert Engine, Voice Assistant (Narada), Mode Controller, and Presence Monitor, all of which are driven by detection events and collectively decide what actions to take based on the current operating mode. The web server and persistence layer (bottom) handles all external communication — FastAPI with Cloudflare tunnel, PBKDF2-based auth, the 180-second deadman watchdog, and the multi-tier logging engine — with every engine above it writing events into this layer for storage and client delivery.
