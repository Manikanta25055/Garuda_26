Hardware Layer — Project Garuda

The hardware layer consists of a Raspberry Pi 5 as the central host board, paired with a Hailo-8L AI HAT+ connected over a PCIe Gen3 ×1 M.2 M-Key interface. The Pi 5 runs a BCM2712 quad-core Cortex-A76 processor at 2.4 GHz with 8 GB LPDDR4X RAM on 64-bit Raspberry Pi OS, hosting the HailoRT driver (hailo_pci DKMS module), the TAPPAS 3.x framework, GStreamer, and the Garuda web server. The Hailo-8L AI HAT provides 13 TOPS of neural processing and is exposed to the OS as /dev/hailo0; it executes all model inference — YOLOv8/v6 detection, MobileNetV2 classification, and MiDaS depth estimation — fully offloaded from the CPU. Video input is sourced either from a USB camera captured via V4L2 (GStreamer v4l2src, /dev/video0) or a Raspberry Pi Camera Module over the CSI-2 MIPI connector (GStreamer libcamerasrc via libcamera). The Pi's network interface — Gigabit Ethernet or 802.11ac WiFi — serves two roles: outbound connectivity through a Cloudflare tunnel for remote web access, and local ARP scanning for LAN device presence monitoring. Model files (.hef), the OS, and all persistent logs are stored on microSD or an external USB SSD.
