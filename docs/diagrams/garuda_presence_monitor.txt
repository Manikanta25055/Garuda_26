The Presence Monitor (Garuda_web.py _presence_poller, L2106–2155) tracks the online/offline status of known LAN devices by running periodic ARP scans from the Pi itself, issuing arp-scan or ip neigh commands via subprocess and parsing the MAC address results. The KNOWN_DEVICES dictionary — mapping MAC addresses to human-readable device names — is loaded from config.json at startup and can be updated at runtime through the /api/devices REST endpoint followed by save_config (L580). After each scan, the engine compares the discovered MAC set against the previous state stored in _device_presence; a transition from offline to online or from online to offline triggers a change event that is immediately pushed to all connected WebSocket clients via push_urgent_ws, allowing the dashboard to update device status indicators in real time without polling. The scan interval is tunable through the configuration, and unknown MAC addresses discovered on the network are reported as unrecognised devices so the administrator can decide whether to add them to the registry.
