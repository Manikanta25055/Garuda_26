The Mode Controller (Garuda_web.py L190–232, L2637–2653, L2076–2105) manages six boolean operating flags — MODE_DND, MODE_EMAIL_OFF, MODE_IDLE, MODE_NIGHT, MODE_EMERGENCY, and MODE_PRIVACY (default True) — that gate behaviour across every other engine. All flag reads and writes are serialised through _mode_lock (threading.Lock, L209) to prevent race conditions between the GStreamer callback thread, the schedule daemon, and the web request handlers. User-defined modes beyond the built-in six are stored in the CUSTOM_MODES registry and can be created or deleted via the config API. The _schedule_monitor daemon (L2076) wakes every 30 seconds and calls _time_in_range (L2070) against entries in the MODE_SCHEDULE dictionary loaded from config.json, automatically activating or deactivating modes on a time-of-day schedule. Runtime changes to any flag — whether from the REST API (POST /api/modes, L2637), from the voice assistant, or from the scheduler — are immediately persisted to config.json via save_config (L580) and are restored on next startup through load_config.
