The Web Server (Garuda_web.py run_web_app L3486) runs a FastAPI application under Uvicorn bound to 127.0.0.1:8080, exposed to the internet through a Cloudflare tunnel at garuda.veeramanikanta.in; CORS is restricted to veeramanikanta.in, vercel.app, and localhost origins. The application defines approximately 45 REST routes organised into functional groups: authentication (/login, /logout, /otp, /reset-password, /master-key), system state (/api/state, /api/modes, /api/config), logging (/api/logs/*, /api/events with SQLite-backed catch-up for offline clients), conversational AI (/api/chat/stream served as Server-Sent Events against the Groq API), device and user management (/api/devices, /api/users, /api/feedback), and media delivery. Media is served through three parallel channels: an MJPEG endpoint at /stream that pulls the current annotated frame from the user_app_callback_class frame buffer, WebSocket endpoints at /ws and /ws/stream for real-time alert and frame push, and a WebRTC track (GarudaVideoTrack, L878) via aiortc for low-latency peer connections. Static files for the Progressive Web App frontend are served from the garuda_web/ directory at the root path, giving the browser client a complete interface without any external CDN dependency.
