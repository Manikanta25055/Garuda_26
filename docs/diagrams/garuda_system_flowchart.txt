Project Garuda System Flowchart — Description

The system captures video frames via a Sony IMX708 camera, preprocesses them through a GStreamer TAPPAS pipeline, and runs YOLOv8s object detection on a Hailo-8L NPU (13 TOPS) with NMS post-processing (IoU ≤ 0.45, confidence ≥ 0.35). Detected objects are classified as watch labels (person, backpack) or danger labels (knife, scissors, hammer); danger detections passing a consecutive-frame check and mode gate trigger email alerts (SMTP-SSL, 60s cooldown), WebSocket push notifications, and AES-256-CBC encrypted clip uploads, while a privacy mode applies Gaussian blur (k=51, σ=30) on person bounding boxes before streaming via MJPEG/WebRTC. Parallel subsystems include the Narada voice assistant (Google STT → rule-based dispatcher / Groq gpt-oss-10b LLM), ARP-based presence monitoring (30s poll, 90s grace), a deadman switch (180s heartbeat timeout → tamper alert), scheduled mode transitions, PBKDF2-SHA256 authentication (600k iterations, OTP 2FA), and a FastAPI web server tunneled through Cloudflare to garuda.veeramanikanta.in.
