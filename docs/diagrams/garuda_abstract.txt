Project Garuda is an AI-powered home security system running on a Raspberry Pi 5 with a Hailo-8L neural processing unit, delivered as a web application accessible remotely via a Cloudflare tunnel at garuda.veeramanikanta.in. The core inference pipeline uses GStreamer with the TAPPAS framework to feed video frames into YOLOv8/v6 models on the Hailo-8L, detecting persons (silently logged) and dangerous objects — knives, scissors, and hammers — which trigger the alert system. Alerts are dispatched as OTP-authenticated SMTP emails with a 60-second cooldown; video clips can be recorded, AES-256 encrypted, and exfiltrated over SSH to a remote host. The web server is a FastAPI application served by uvicorn, exposing a PWA frontend and a REST API secured with PBKDF2-SHA256 session authentication, a master key system, per-endpoint rate limiting, and strict CORS and security header policies. A voice assistant named Narada runs as a background thread using speech recognition with a configurable wake word, dispatching commands via rule-based matching or a Groq LLM (llama-3.3-70b-versatile), which also powers a streaming chat interface in the web UI. The system supports six operating modes — Do Not Disturb, email-off, idle, night, emergency, and privacy — configurable manually or via a time-based schedule. Additional subsystems include ARP-based LAN device presence tracking, a 180-second deadman watchdog that fires a tamper alert on missed heartbeats, a WebRTC and MJPEG live video streaming interface, a SQLite-backed offline event sync queue, and a multi-tier logging pipeline writing to persistent text and JSON files with log rotation.
