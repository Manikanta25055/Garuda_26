Project Garuda is an embedded AI home security system deployed on a Raspberry Pi 5 with a Hailo-8L neural processing unit. It performs real-time object detection using YOLOv8 and YOLOv6 models through a GStreamer-TAPPAS hardware-accelerated inference pipeline, identifying persons, animals, and flagged dangerous objects (e.g., scissors) with classification and bounding-box overlays at the edge. Detected events trigger a coordinated multi-modal response: a voice assistant (Narada) announces alerts verbally via speech synthesis, an email alert engine sends OTP-authenticated notifications with configurable cooldown, and a GPIO hardware interface activates an HC-SR04 ultrasonic proximity sensor, LED indicators, and physical buttons for on-site feedback. The system adapts autonomously to low-light conditions through a dedicated night mode engine with separate detection logic, and all detection events, alerts, and operational state are persisted to JSON-structured logs with 7-day rolling retention. A PyQt5 GUI dashboard provides operators with live status monitoring and manual control over system modes including Do Not Disturb, idle, and night operation, with role-based login for admin and user access.
